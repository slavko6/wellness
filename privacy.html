Privacy policy

Last updated: 4 October 2026

Who uses this app

Wellness is a personal project used only by its owner. It is not available to other users.

What data it accesses

With the owner's consent, the app reads the owner's own data from the Google Health API (read-only): activity and fitness data, health metrics and measurements, and sleep data.

How the data is used and stored

  • Data is downloaded directly to the owner's own computer and stored there in a local database.
  • It is used only to show the owner their own trends in a personal dashboard.
  • It is never sold, shared with, or transferred to third parties, and is not used for advertising.
  • The app never writes or changes any data in Google Health.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access stops all further data collection; locally stored data can be deleted by the owner.
